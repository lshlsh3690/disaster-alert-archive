# 클러스터링 평가 셋 판정 기준 (2026-10-11 확정)

두 재난문자가 **같은 사건**인가?

1. 같은 지역·같은 에피소드(특보 발효~해제, 하나의 사고) → **같은 사건**
2. 인접 지역이고 같은 개체/현상이 이어진 경우(동물 이동, 산불·사고 확산, 실종자 이동 등. 문자에 연속성 단서가 있어야 함) → **같은 사건**
3. 별개의 사고·사건(각각 다른 장소·번지의 화재, 서로 다른 지점의 시설 파손 등)이거나, 같은 기상 상황이 서로 다른 지역에서 병렬로 안내되는 경우 → **다른 사건**
4. 같은 지역·같은 유형의 되풀이 안내문(폭염·한파·산불 예방 등)과, 같은 기상 에피소드의 안내와 특보 → **같은 사건**

판단이 안 서면 "모르겠음"(지표 계산에서 제외).
