# 대시보드 지도 경계 데이터 (시군구 / 읍면동)

홈 대시보드 지도(`src/components/map/KoreaMap25D.tsx`)의 **시군구 보기**와, 시군구를 눌렀을 때 확대되는 **읍면동**
경계를 만든다. 시도 경계는 `koreaSido.data.ts`(자동 생성 파일)에 따로 들어 있어 여기서 만들지 않는다.

## 만들어지는 파일 (`frontend/public/map/`)

| 파일 | 내용 | 용량(2026-09판 기준) |
|---|---|---|
| `sigungu.json` | 시군구(코드 5자리) 256개. 이름 `n`, 경로 `d`, 말풍선 기준점 `p`, 확대용 경계 상자 `b` | 약 0.95MB |
| `emd/<시도 2자리>.json` | 읍면동(코드 8자리). 시도별 파일 16개. `b` 없음 | 시도당 16KB~494KB(전체 2.7MB, 필요한 시도만 받는다) |

구가 있는 시(수원시 장안구 등)는 구 단위(5자리 `41111`)로 나뉘고, 시 전체(`41110`)는 폴리곤이 없다.
좌표는 `koreaSido.data.ts` 와 같은 화면 좌표(px)라 시도 보기와 겹친다. 확대(`KoreaMap25D`)는 `b` 로 viewBox 를 계산한다.
시도 보기에서 시도를 누르면 그 시도에 속한 시군구의 `b` 들을 합쳐(`unionBBox`) 확대하고, 시군구를 누르면 그 시군구의 `b` 로 읍면동을 확대한다. 시도 코드는 시군구 코드 앞 2자리와 같다.

## 입력 (PostGIS 테이블 3개)

| 테이블 | 만드는 법 |
|---|---|
| `emd(emd_cd, emd_nm, geom)` | 국가공간정보포털 법정구역 읍면동 `LSMD_ADM_SECT_UMD`(2026-09판, 시도별 SHP)를 SRID 5186 으로 적재한 `emd_raw`(5,373행)에서 **`emd_cd` 가 8자리 숫자인 행만** 남긴 것(오염 행 306개 제외 → 5,067행). `CREATE TABLE emd AS SELECT * FROM emd_raw WHERE emd_cd ~ '^[0-9]{8}$';` |
| `off8(code8, name, is_active)` | 행정표준코드관리시스템 법정동코드 전체자료에서 읍면동 행(코드 3~5번째 자리 ≠ `000`, 6~8번째 자리 ≠ `000`, 9~10번째 자리 = `00`)의 앞 8자리 + 이름 + 활성(`존재`) 여부 |
| `sg_names(code5, name)` | 같은 자료에서 시군구 행(3~5번째 자리 ≠ `000`, 6~10번째 자리 = `00000`, 활성)의 앞 5자리 + 이름 |

경계 파일을 어디서 받았는지(URL), 라이선스는 이 저장소에 기록하지 않았다. 갱신할 때 출처와 이용 조건을 먼저 확인할 것.

## 실행

```bash
cd frontend
PSQL="docker exec -i tmp-postgis psql -U postgres -d gis" bash scripts/map-regions/generate.sh
```

`generate.sh` 가 `build.sql`(좌표 변환·시군구 병합) → `export.sql`(JSON 출력)을 호출하고 `node` 로 JSON 을 공백 없이 줄여 저장한다.
임시 파일에 쓰고 성공했을 때만 교체하며, `build.sql` 이나 export 가 실패하면 스크립트가 멈춘다(실패한 뒤 낡은 테이블로 JSON 을 만들지 않는다).
`PSQL` 은 PostGIS 가 설치된 DB 에 접속하는 `psql` 명령이다. 이 저장소에는 PostGIS 컨테이너/DB 를 만드는 설정이 없으므로,
위 입력 테이블 3개를 만든 PostGIS DB 를 직접 준비해야 한다(`CREATE EXTENSION postgis`). 이 작업 때는 `postgis/postgis` 이미지의
임시 컨테이너(`tmp-postgis`, DB `gis`)를 썼다.

## 투영 (기존 시도 지도와 겹치게 맞춘 값)

기존 `koreaSido.data.ts` 의 시도별 최대 다각형 무게중심을 옛 `public/sido.geojson`(카카오맵 제거 때 삭제, git 이력에 있음)과 비교해 구했다(오차 0.4px 미만):

```
화면 x = 98.0650 * lon      - 12195.995
화면 y = -98.1811 * mercY    + 4138.969      (mercY = ln(tan(π/4 + lat/2)) 의 도 단위)
```

EPSG:3857(미터)의 아핀 계수로 환산하면 `build.sql` 의 `:sx :sy :ox :oy` 가 된다.

| 변수 | 값 | 의미 |
|---|---|---|
| `sx` | 0.0008809328833718087 | `98.0650 * 180 / (π * 6378137)` |
| `sy` | 0.0008819758274166715 | `98.1811 * 180 / (π * 6378137)` |
| `ox` | -12195.995 | x 오프셋 |
| `oy` | 4138.969 | y 오프셋 |

`ST_AsSVG` 는 출력할 때 Y 부호를 뒤집는다. 그래서 `build.sql` 은 y 계수/오프셋의 부호를 반대로 두고(`+sy`, `-oy`),
`export.sql` 은 말풍선 기준점 `p` 와 경계 상자 `b` 의 Y 를 다시 뒤집어 낸다.

## 단순화 허용오차

| 파일 | 허용오차(px) | 이유 |
|---|---|---|
| `sigungu.json` | 0.4 | 전국 보기용. 확대 화면에서는 배경으로만 쓴다 |
| `emd/*.json` | 0.06 | 시군구를 확대하면 1 단위가 수십 화면 픽셀이 되므로(작은 구역은 약 60px 이상) 0.35 에서는 도형이 투박하다 |

값을 낮추면 매끈해지지만 파일이 커진다. `ST_SimplifyPreserveTopology` 를 구역별로 따로 적용하므로 이웃한 구역 사이에
미세한 틈이 생길 수 있다 — 지도는 확대 때 시도 윤곽과 선택한 시군구의 거친 윤곽을 바닥에 깔아 틈이 비치지 않게 한다.

## 행정구역이 개편되면

1. 새 경계 파일과 새 법정동코드 전체자료로 입력 테이블 3개를 다시 만든다.
2. **코드가 바뀐 읍면동**을 확인한다. 아래 쿼리가 0 이 아니면 경계 코드와 현재 법정동코드가 어긋난 곳이다.
   ```sql
   SELECT 'boundary-only', e.emd_cd, e.emd_nm FROM emd e
   WHERE NOT EXISTS (SELECT 1 FROM off8 o WHERE o.code8 = e.emd_cd AND o.is_active);
   SELECT 'official-only', o.code8, o.name FROM off8 o
   WHERE o.is_active AND NOT EXISTS (SELECT 1 FROM emd e WHERE e.emd_cd = o.code8);
   ```
   2026-09판은 구지면(`27710380`) → 구지읍(`27710268`) 한 건이 어긋났고(읍 승격), `build.sql` 의 `CASE` 로 보정했다.
   새로 어긋나는 코드가 생기면 같은 방식으로 `build.sql` 에 보정을 추가한다.
3. `generate.sh` 를 다시 실행하고 `git diff --stat public/map` 으로 변경 규모를 확인한다.

## 경계 상자(`b`)와 말풍선 기준점(`p`)

시군구의 `b` 와 `p` 는 viewBox(`0 0 682 714`) 안에 **보이는 부분**으로 계산한다(`export.sql`). 울릉군은 독도(x≈737)를 포함하는데
viewBox 밖이라 그대로 계산하면 확대 화면이 오른쪽으로 쏠리기 때문이다. 경로(`d`)는 자르지 않는다 — 밖에 있는 부분은 그려지지 않을 뿐이다.

## 한계

- 이름 조인이 `off8.is_active` 만 보므로, 활성이 아닌 코드의 경계가 남아 있으면 이름이 빈 문자열이 된다(현재는 0건).
- 리(10자리) 단위 경계는 없다. 알림이 리 코드로 걸린 경우 백엔드가 읍면동(8자리)으로 합산한다.
- 구가 있는 시(수원·화성 등)는 시 전체 단위로 온 알림이 구 폴리곤에 매칭되지 않아 지도에는 0건으로 보인다.
- 독도는 화면 좌표 x≈737 로 `KoreaMap25D` 의 `viewBox`(0 0 682 714) 밖이라 보이지 않는다(기존 시도 지도도 독도를 그리지 않는다). 울릉도(x≈641)는 보인다.
- 읍면동 이름은 한국어 공식 명칭만 있다(번역 없음).
